# Security

Do not post vulnerabilities, credentials, provider profiles or private account data
in public issues. Contact security@quorilo.app privately with a minimal description,
version/source identity and impact; redact secrets. Do not send passwords/tokens.
The existing owner-controlled address is reused; no response SLA is promised.

Local Free access never grants hosted/account/owner privileges. Signed update and
package-integrity checks must remain enforced. Build outputs are candidates until
independently accepted. Testing is limited to systems/accounts you may use; do not
probe production or other users. Do not install private Stripe TEST candidates.
