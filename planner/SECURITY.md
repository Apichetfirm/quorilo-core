# Security and responsible disclosure

This is an unreleased private candidate, not a trusted authority for provider
availability, billing or task execution. It performs no privileged actions.

Before public publication the maintainer must configure and verify a private
reporting channel in the selected repository and list supported release versions.
Do not put credentials, personal data or exploit material into public issues.
No disclosure inbox or private reporting capability is claimed configured here.

Report privately through that approved channel once available, including version,
minimal synthetic reproduction and expected/actual behavior. Never send tokens,
provider account data or raw personal logs. A security report is not consent to
perform intrusive testing against hosted Quorilo services.
