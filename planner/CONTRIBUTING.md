# Contributions

This component uses the MIT license in LICENSE. Contributions accepted after
public release must be provided under that same license, with the contributor's
required notices preserved. No copyright assignment or additional relicensing
rights are implied. No CLA or DCO requirement is currently imposed.

External contributions remain closed until public release and the private
security reporting channel are configured. Once open, keep changes focused,
use synthetic fixtures, run npm test and npm run build, and avoid introducing
telemetry/private services/dependencies without review. Document compatibility
and retain required notices. Never submit credentials, customer data or
code/assets you are not entitled to license.
