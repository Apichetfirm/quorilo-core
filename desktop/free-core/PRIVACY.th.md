# Quorilo Monitor Free Core · private prerelease

Free Core อ่านข้อมูลโควตาจากบริการ AI ที่ผู้ใช้เชื่อมเอง และเก็บการตั้งค่า โปรไฟล์
ประวัติ และการแจ้งเตือนในบัญชี Windows ของผู้ใช้ ไม่ต้องมีบัญชี Quorilo หรือส่ง
ข้อมูลเพื่อตรวจ Trial/สมาชิก Stripe การเข้าสู่ระบบและค่าใช้จ่ายของผู้ให้บริการ AI
ยังเป็นเรื่องแยกต่างหาก ข้อมูลที่ผู้ให้บริการรายงานอาจล่าช้าหรือไม่ครบทุกโควตา
Gemini CLI ใช้เฉพาะ session ใน cache ของ CLI ที่ยังไม่หมดอายุ ไม่ bundle client
secret ไม่ refresh OAuth หรือแก้ cache หากหมดอายุต้องเชื่อมใหม่ด้วย CLI ของผู้ให้บริการ

การเก็บประวัติเป็นตัวเลือกในเครื่อง ค่า credential ของบริการเสริมที่ผู้ใช้กรอก
เก็บด้วย Windows DPAPI ไม่คัดลอกบัญชีจาก browser โปรไฟล์ที่เพิ่มแยกจากบัญชีหลัก
Free Core ไม่โหลดสิทธิ์บัญชี Quorilo หรือข้อมูลจับคู่ Companion เดิม และไม่เปิด
Cloud Sync การอนุมัติระยะไกล หรือการส่งงานอัตโนมัติจากสิทธิ์ฟรี

ใช้ตำแหน่งการตั้งค่าและโปรไฟล์เดิมเพื่อความเข้ากันได้ ไม่ลบหรือแก้ประวัติชำระเงิน
Trial หรือไฟล์สิทธิ์เดิม ประวัติโควตาและ credential บริการเสริมของ Free Core
ใช้ขอบเขต local `free-core` แยกจากขอบเขตบัญชี/Owner เดิม โดยเก็บไฟล์เดิมไว้
ประวัติ Insights และการตั้งค่ามอนิเตอร์ในเครื่องเดิมยังใช้ต่อได้

การเผยแพร่ source/โปรแกรมยังรอการตรวจอิสระและการอนุมัติของ Founder
